### 🔹 Featured Project Highlights

**1. Customer Churn Prediction**
- Developed an end-to-end machine learning pipeline using 7,000+ telecom customer records.
- Compared Logistic Regression, Random Forest, and XGBoost.
- Addressed 26% class imbalance using class weighting.
- Achieved **0.85 ROC-AUC** and approximately **80% recall** for churn prediction.
- Applied RandomizedSearchCV and SHAP for hyperparameter tuning and model explainability.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, XGBoost, SHAP, Matplotlib, Seaborn.

**2. Argus Investment Research Agent**
- Developed an AI-powered investment research agent using an 8-node LangGraph state graph.
- Integrated SEC EDGAR, Financial Modeling Prep, and Tavily APIs.
- Implemented four parallel research agents for financial information gathering.
- Used Llama models for research summarization, investment decisions, and self-critique.
- Implemented Zod schema validation for structured and reliable outputs.

**Tech Stack:** React, Next.js, LangChain.js, LangGraph.js, Groq API, Llama, Zod.

**3. Power BI Crime Dashboard**
- Analyzed **3.93M+ crime records** across 36 Indian states and union territories (2003–2013).
- Performed ETL, data cleaning, and transformation using Power Query.
- Created DAX measures and interactive multi-page dashboards.
- Identified Uttar Pradesh and West Bengal as major contributors to reported incidents.
- Designed interactive maps, rankings, and slicers for regional exploration.

**Tech Stack:** Power BI, Power Query, DAX.
